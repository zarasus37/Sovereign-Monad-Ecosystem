# Ecosystem Build Map

This is the companion build map for the Sovereign Monad ecosystem.

Use it as the structural guide for where active work belongs.

## Active Domains (live set)

- `theo-techno-cosmo/` - philosophical and doctrinal material
- `gnostic-engine/` - volumetric 4D processing engine
- `gnosis-training/` - preference / reward / SFT pipeline
- `monad-ecosystem/` - packages (ttcl, gate-acl, bus, host, organs), control center, contracts
- `shared/` - schemas + constraint packs

## Supporting Areas

- `docs/` - canonical operating documents — start at **`docs/CANON.md`**
- `docs/PROJECT_STATE.md` - resume checkpoint for the current project state
- `docs/P0_MONOREPO_HYGIENE.md` - live vs archive rules
- `scripts/` - workspace orchestration and verification
- `archive/` - **frozen** legacy / generated / sandboxes — do not import into live code

## Reading Rule

If a file or folder conflicts with the MOF, the MOF wins.  
If two docs conflict, use **`docs/CANON.md`**.
