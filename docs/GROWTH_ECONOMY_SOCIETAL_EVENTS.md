## 3. Societal mind (depth, not XP)

### 3.1 Definition

**Societal mind** = the aggregate capacity of Meshaleachs, Shaliahs, and autonomous agents to:

- Know and refuse under pressure  
- Coordinate without permanent caste  
- Raise the **floor** while allowing peaks  
- Host healthy competition that makes everyone more capable  

**Levels** = depth of that collective mind (what the society can hold), not a single-player level map.

```text
Individual mind
  → Human↔Shaliah cell (extension + coach)
    → Cohorts / guilds
      → Open arenas + seasons
        → Council / structural autonomous work
          → Societal mind (tap-able network of competence)
```

### 3.2 Healthy competition

| Healthy | Toxic |
|---------|-------|
| Raises competence floor | Humiliates or extracts the weak |
| Shared rules, public integrity | Hidden griefing of learners |
| Scores multi-objective growth | Pure PnL / pure vanity |
| Rewards teaching and bridging | Pure private hoarding |
| Stretch problems, novel variants | Farming static content |
| Autonomous agents as worthy rivals | Agents as pure predators of humans |

Competition is a **learning institution** (deliberate practice + relatedness), not a coliseum for atrophy of the bottom.

## 4. Societal events (group forms)

Events are how **individuals become a society you can tap**. They also implement **distributed practice and interleaving at social scale**.

### 4.1 Event types (v1 catalog)

| Event | Form | Learning science | Economy |
|-------|------|------------------|---------|
| **Seasonal campaign** | Time-boxed shared regime (e.g. adverse-selection season) | Spacing + society-wide interleaving | Bounties; season treasury; growth-cut optional boost |
| **Cohort arena** | Small group (e.g. 8–50) internal rank + **cohort score** | Relatedness + collaborative competence | Cohort pool; split on multi-objective success |
| **Open tournament** | Public skill under shared law | Deliberate practice; transfer variants | Prize pool; status; access unlocks |
| **Teach-to-earn bridge** | Higher-depth participants raise others | Cognitive apprenticeship; entanglement | Bridge rewards from season/growth pools |
| **Structural job fair** | Autonomous + human tasks that serve real structure | Situated learning; DeFi/world interface | Job bounties; SA pool demand |
| **Council / societal problem** | Polyphonic problem with shared axioms | Collective mind; multi-perspective integration | Prestige; mandate influence; limited material reward |

### 4.2 Event design laws

1. **Every event teaches something nameable** (doctrine or skill), not only entertainment.  
2. **Scoring multi-objective** — outcome × constraint fidelity × transfer / integrity.  
3. **Novel variants** inside seasons so farming dies.  
4. **Bridge surfaces** — winners leave paths for others (CCM entanglement).  
5. **Shaliah coach mode** active for human-bound players; no silent autopilot wins.  
6. **Autonomous agents** may compete or staff structural roles under same scoring ethics.  
7. **Load control** — event UI does not bury decisions in lore.  
8. **Aftermath retrieval** — short post-event “why” for participants (practice testing).

### 4.3 Example season (illustrative)

**Name:** Density Under Volume  
**Sport:** Paper or testnet activity where volume temptation fights density floor.  
**Individual:** Operate under C-DENSITY / anti-dilution; Shaliah coaches stretch.  
**Group:** Cohort score for constraint-faithful growth, not max volume.  
**Pay:** Bounties + optional growth-cut yield from productive pools funding the season.  
**Aftermath:** Forced retrieval — when did density save you; when did you almost dilute?
