## 3. Middle (J4–J8) — operational integration

This is where the institution actually lives. Middle is not “more minigames”; it is **situated life under law** with Shaliah as coach and Integrity as certifier.

### J4 — Operator apprenticeship (paper)

| Element | Spec |
|---------|------|
| **Capital tier** | Paper / sandbox only (live still gated) |
| **Shaliah role** | Full coach + mirror + attention shield; models expert constraint reasoning, then fades on mastered sub-skills |
| **Player role** | Operates under TTC/Hepar/density/refusal; owns decisions |
| **Multitude** | Limited sandbox agents (adversaries/peers) under Efficiency budget |
| **Learning** | Core loop: situation → decision → consequence → retrieval → imprint update |
| **Exit toward J5** | Repeated voluntary ops + basic spaced return; no permanent “I cleared onboarding” freeze |

**Anti-patterns:** silent autopilot success; lore walls mid-decision; PnL-only dashboards.

### J5 — Anti-Grind continuous loop (Proof of Cognition)

| Element | Spec |
|---------|------|
| **Learning Constitution** | Progress requires **Stretch** (higher ZPD tiers) + **Transfer** (cross-module application) |
| **Telemetry** | Sequences, latency, trajectories; stealth assessment |
| **Integrity metric** | \(I_i = \alpha N_i + \beta C_i + \gamma P_i\) with frozen weights (see §5) |
| **Components** | \(N_i\) Navigation Authenticity · \(C_i\) Context Alignment · \(P_i\) Progressive Differentiation |
| **Signing** | Integrity Auditor cryptographically signs telemetry → eligible achievement / yield routing |
| **Stretch band** | Plateau (templated, fast, high success) → novel variants; overload → scaffold without removing essential challenge |
| **Reflective design** | Endo (in-world failure) + exo (Shaliah / peer / debrief retrieval) |
| **Exit toward J6** | First Integrity-signed productive yield epochs; Growth Capital may arm |

**Anti-patterns:** repetitive loop points; external botting; prompt injection for fake mastery.

### J6 — Growth Capital engages (wealth while learning)

| Element | Spec |
|---------|------|
| **Eligible \(C\)** | Productive on-chain yield from learner transactional activity + system contributions, **only if Integrity-signed** under Learning Constitution |
| **Default rate** | \(r = 0.20\) locked until FG-3; post-grad \(r \in [0.05, 0.30]\), ≤1 change/30d; opt-in seasonal +1–2 pp |
| **Cut** | \(G = r \cdot C\) |
| **Bank-style model** | **Unitized personal claim + collective NAV pool** |
| **Routing** | \(\alpha/\beta/\gamma = 0.40/0.35/0.25\) → claim / community / job escrow |
| **Deployment** | Pool base + Shaliah propose + human confirm by risk tier |
| **Liquidity** | Soft commitment + emergency path; optional hard goal vault |
| **FG path** | FG-1 → FG-2 → FG-3 (transfer gates; rate sovereignty at FG-3 only) |
| **Shaliah** | Coach + steward under policy-as-code; never sets \(r\) for the human |
| **Momentum agent** | Collective deployment velocity; growth options |
| **Exit toward J7** | Claim + NAV readable; safe deploys if FG-1; pool-funded events; FG path visible |

### J7 — Societal events (societal mind middle)

|-------------|----------------------|-----------|

| Element | Spec |
|---------|------|
| **Shaliah** | Coach mode active; no silent autopilot event wins |
| **Aftermath** | Forced retrieval: why density saved you / almost diluted |

### J8 — Autonomous Multitude interface

| Element | Spec |
|---------|------|
| **World** | Full Multitude: wallets, alliances, trades, betrayals—non-deterministic sandbox |
| **Player** | Competes / collaborates under **same axioms** as synthetic minds |

## 5. Frozen operational parameters (integration)

These close the open decisions in `docs/SOVEREIGN_COGNITION_ARCHITECTURE.md` §11.

### 5.1 Growth Capital rate, bank model, and channel weights

**v1 policy:** founder-accepted research defaults (`docs/OPEN_DECISIONS_RESEARCH.md`, 2026-07-26).

| Symbol / rule | Value | Meaning |
|---------------|-------|---------|
| \(r_{\text{default}}\) | **0.20** | Default Growth Capital allocation (20% of eligible \(C\)) |
| Pre–Financial Graduation | \(r\) **locked** at 0.20 | User cannot change rate |
| Post–Financial Graduation | User sets \(r \in [0.05, 0.30]\) | Floor 5% / ceiling 30%; **max 1 change per 30 days** |
| Auto-escalate | Opt-in **+1–2 pp per season** (user confirm) | SMarT-style; Shaliah may propose, human owns |
| \(r = 0\) | **Not allowed** in v1 normal path | Optional harder path only in later policy |
| Accessibility | **Not a dead lockbox** | Claim always tracked; capital deploys to grow. Gated = rate control + high-agency decisions |
| Bank-style collective | **Unitized claim + collective NAV pool** | Personal units always ledgered; funds deploy collectively |
| Deployment | Pool base + Shaliah propose + **human confirm by risk tier** | No silent autopilot; no user micro-trade overload |
| Liquidity | **Soft commitment** + emergency path; optional hard goal vault | Scheduled windows + coach/Integrity hardship path |
| \(\alpha\) | **0.40** | → personal-claim / future-oriented growth |
| \(\beta\) | **0.35** | → Productive Community Pools |
| \(\gamma\) | **0.25** | → Job-Matching Escrow / talent rails |

\[
G = r \cdot C, \qquad r_{\text{default}} = 0.20
\]

\[
S_{\text{claim}} = \alpha G, \quad
P_{\text{comm}} = \beta G, \quad
E_{\text{escrow}} = \gamma G
\]

with \(\alpha + \beta + \gamma = 1\).

### 5.1.1 Financial Graduation (FG-1 → FG-2 → FG-3)

Distinct from door graduation (J3). **Transfer-based, not quiz.** Arms Growth Capital at first Integrity-signed eligible \(C\); unlocks **rate sovereignty** only at FG-3.

**Full lesson map:** `docs/FG_CURRICULUM.md` (L1.1–L3.G, spacing, Integrity, Shaliah duties).

| Gate | Unlocks | Proof |
|------|---------|--------|
| **FG-1** Literacy in action | Full claim statement; **safe** deployment menu | Integrity-signed transfer across ≥3 domains (DeFi sim, time preference, one non-crypto surface) |
| **FG-2** Stewardship | Confirm higher-risk moves; deeper channel literacy | Spaced re-performance + self-explain a drawdown; no autopilot Shaliah win |
| **FG-3** Rate sovereignty | User may set \(r \in [0.05, 0.30]\) | Delayed transfer battery + rate-choice simulation (5% vs 20% vs 30%) with coach debrief |

### 5.1.3 L4 posture (v1)

**Gated, unscheduled.** Digital OS does not depend on L4. First pilot only if: J5 live, J6 paper/testnet real, ≥1 J7 season done, Integrity+Efficiency multi-user stable, legal/safety owner assigned. Pilot shape: 12–40 people, 2–4 weeks, one guild/season theme.

### 5.2 Integrity metric (same weight triple)

Proof of Cognition verification for learner \(i\):

\[
I_i = \alpha N_i + \beta C_i + \gamma P_i
\]

| Symbol | Name | Role |
|--------|------|------|
| \(N_i\) | **Navigation Authenticity** | Real human trajectory vs bot / Sybil / scripted farm |
| \(C_i\) | **Context Alignment** | Decision fit to regime, constraints, stated goals |
| \(P_i\) | **Progressive Differentiation** | Stretch into higher tiers + non-repetitive progress |

**Design note:** The same \((\alpha,\beta,\gamma)\) couple **capital routing priorities** to **integrity scoring priorities** in v1.

### 5.3 Eligible \(C\) (cognitive yield)

**Eligible \(C\)** = total **productive, on-chain yield** from:

1. Learner transactional activity, and  
2. System contributions  

**only when** the Integrity Auditor has **cryptographically signed** the underlying telemetry as having passed multi-objective Proof of Cognition under the Learning Constitution (verified higher-difficulty progression + conceptual transfer across modules—not mechanical grind).

Unsigned or failed-\(I_i\) yield is **not** routable as growth-cut base.

### 5.5 Control-plane hosting model

| Property | Spec |
|----------|------|
| **Agents** | Integrity Auditor, Build Momentum Accelerator, Adaptive Efficiency Optimizer |
| **Execution** | **Sovereign AI execution architecture** |
| **Hosting** | Private, **self-hosted enterprise** infrastructure |

**Boundary:** Control plane is infrastructure. It does **not** host the user’s Shaliah as a co-sovereign mind; Shaliah remains the personal vehicle under human principal + policy-as-code.
